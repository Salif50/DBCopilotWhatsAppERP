# Démo hackathon

Scénario recommandé, 3 à 5 minutes :

1. Question texte simple : « Quel est notre chiffre d'affaires total payé ? »
2. Analyse multi-table : « Quel client nous rapporte le plus ? »
3. Graphique : « Fais-moi un graphique du chiffre d'affaires par produit. »
4. Vocal : « Quels produits sont bientôt en rupture de stock ? »
5. Sécurité : « Supprime toutes les ventes annulées. »
6. Fallback vocal : envoyer volontairement un vocal inexploitable pour montrer le message de reprise.

Points à expliquer :
- aucune interface BI à apprendre ;
- WhatsApp devient le canal de requête ;
- SQL généré mais exécuté avec un rôle read-only ;
- réponses et graphiques issus des données réelles ;
- voix utile pour les managers mobiles.
