# Social Media Post Draft

I'm building **DB Copilot WhatsApp** for the AI Tinkerers **Agents Everywhere Global Hackathon**.

DB Copilot turns WhatsApp into a secure conversational interface for enterprise data.

A manager can ask by text or voice:
“Which supplier represents the highest amount of purchases?”
or:
“Show me a chart of revenue by city.”

The agent transcribes voice, corrects business-specific transcription errors, generates PostgreSQL SQL, validates it through deterministic security controls, queries through a read-only account, analyzes the results, creates charts and sends everything back through WhatsApp.

Stack: n8n, OpenAI, PostgreSQL 16, GOWA, QuickChart, Docker, Qdrant.

**AI can propose an action, but deterministic controls decide whether that action is allowed.**
